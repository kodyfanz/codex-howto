# Resources

This directory contains original visual assets and reusable resources for Codex
How To.

## Logos

- `logos/codex-howto-logo.svg` — light-background wordmark.
- `logos/codex-howto-logo-dark.svg` — dark-background wordmark.

The mark represents a guided path moving through code brackets. It is original
project artwork and is not an OpenAI product logo.

See the [asset and licensing inventory](../docs/ASSET_LICENSES.md) for origin,
distribution, and screenshot policy details.

## Usage

- Keep the full wordmark legible.
- Preserve the aspect ratio.
- Use the dark variant on dark backgrounds.
- Do not recolor the mark to imply official OpenAI endorsement.
