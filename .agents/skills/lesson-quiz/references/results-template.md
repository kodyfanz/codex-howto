# Quiz report template

```markdown
## Lesson quiz results: [Module name]

**Score:** [N/10] — [Grade]
**Timing:** [Pre-test / Progress check / Mastery check]

### Results

| # | Category | Result | Review |
|---:|---|---|---|
| 1 | [Conceptual/Practical] | [Correct/Incorrect] | [Section or —] |

### Review these concepts

For each miss:

**Question [N]: [short question]**

- Your answer: [answer]
- Correct answer: [answer]
- Why: [explanation]
- Review: [module section]

### Next step

[Timing- and score-appropriate recommendation with a module link.]
```

For a pre-test, frame the result as a baseline. For a progress check, identify
what to revisit before continuing. For a mastery check, recommend moving on only
at 9–10; at 7–8, recommend focused review and a retake.
